# 🚗 GlicApp – Aplicativo par ao controle de glicemia

O **GlicApp** é um aplicativo con controle de glicemia.  
O aplicativo é acessado pelo sistema operacional **android**.

---

## 📱 Aplicativo

O aplicativo mobile é responsável por:

- Registar a medição de dextro do usuário
- Registar os tipos de insulinas e quantidade aplicada
- Realizar o cálculo da média e últimos dextros para o controle do paciente

---

## ⚙️ Tecnologias Utilizadas

### Backend
- C#
- Xamarin

### Frontend
- XAML

### Banco de Dados
- SqLite
